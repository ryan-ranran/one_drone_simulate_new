# D430i 相机与算法启动、验证

本文用于在 Ubuntu 24.04 / ROS 2 Jazzy 下启动 D430i 和 one_drone 算法，并做
**无桨台架检查**。相机驱动与算法是两个独立进程：先启动相机，再启动算法。

> **安全要求：拆除螺旋桨，关闭电机。定位验证期间保持
> `startup.flight_control: false`，不要调用起飞或降落服务。**

## 1. 启动前确认

1. D430i 已通过 USB 连接；检查设备和线缆，避免 USB 带宽不足。
2. 当前终端使用 Jazzy：

   ```bash
   source /opt/ros/jazzy/setup.bash
   ros2 doctor --report
   ```

3. one_drone 工作区已在当前 ROS 发行版下成功编译，并且存在
   `~/one_drone/install/setup.bash`。如果工作区是按 Humble 编译的，不能直接
   在 Jazzy 下使用其 `install` 产物；需先在目标 ROS 环境中安装依赖并重新编译。
   项目内的 `setup_env.sh` 当前检查的是 ROS 2 Humble，不要用它初始化 Jazzy。
4. 确认 D430i 标定目录存在，且 `launch.yaml` 中选择了与当前相机相符的目录。
   本机配置示例为 `~/one_drone/deploy/calibration/d430i`。当前导入结果里的
   IMU 噪声仍沿用 D435i 临时值，`body.yaml` 安装外参也尚未确认，台架结果不能
   作为飞行许可。
5. 本文命令使用 `rmw_fastrtps_cpp`。相机、算法和验证终端必须使用相同的
   `RMW_IMPLEMENTATION` 和 `ROS_DOMAIN_ID`（若设置了该变量）。

## 2. 终端 A：启动 D430i 相机驱动

确认没有另一个 RealSense 驱动已经占用相机，然后在终端 A 运行：

```bash
source /opt/ros/jazzy/setup.bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
ros2 launch realsense2_camera rs_launch.py \
  enable_color:=false enable_depth:=true \
  depth_module.depth_profile:=640x480x30 \
  enable_infra1:=true enable_infra2:=true \
  depth_module.infra_profile:=640x480x30 \
  depth_module.infra1_format:=Y8 depth_module.infra2_format:=Y8 \
  enable_gyro:=true enable_accel:=true \
  gyro_fps:=200 accel_fps:=100 unite_imu_method:=2
```

保持该终端运行。若提示 `Package 'realsense2_camera' not found`，先安装与
当前 Jazzy 对应的 RealSense ROS 驱动；不要改用不存在的
`/opt/ros/humble/setup.bash`。若参数被拒绝或驱动回退了频率，以驱动日志显示的
实际设置为准，并确保和标定使用的图像流、分辨率、左右顺序一致。

另开终端检查话题与参数：

```bash
source /opt/ros/jazzy/setup.bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
ros2 topic list | grep -E 'infra[12]/image_rect_raw|depth/image_rect_raw|imu'
ros2 param get /camera/camera gyro_fps
ros2 param get /camera/camera accel_fps
ros2 param get /camera/camera unite_imu_method
```

应能看到：

- `/camera/camera/infra1/image_rect_raw`
- `/camera/camera/infra2/image_rect_raw`
- `/camera/camera/imu`
- 开启硬件深度时的 `/camera/camera/depth/image_rect_raw` 和对应
  `/camera/camera/depth/camera_info`

检查图像和 IMU 发布频率（每条 `hz` 命令运行数秒后按 `Ctrl+C`）：

```bash
ros2 topic hz /camera/camera/infra1/image_rect_raw
ros2 topic hz /camera/camera/infra2/image_rect_raw
ros2 topic hz /camera/camera/imu
```

预期红外图约 30 Hz，组合 IMU 约 200 Hz；组合 IMU 的 200 Hz 不代表原始加速度计
也是 200 Hz。本机配置为陀螺仪 200 Hz、加速度计 100 Hz，驱动合并输出。
若图像无消息、左右目顺序/格式不符或频率异常，先解决相机问题，不要启动定位。

## 3. 终端 B：启动算法（仅定位台架模式）

算法启动不会替你启动相机；先确保终端 A 的相机话题正常。再开终端 B：

```bash
cd ~/one_drone
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
ros2 launch bringup startup.launch.py \
  sim:=false rviz:=false flight_control:=false \
  localization_source:=openvins \
  calibration_dir:=/home/chenran/one_drone/deploy/calibration/d430i \
  perception_enabled:=false
```
